Once live sync is connected, anything checked off on one phone shows up on the other automatically. If it's not connected, you can still move data over manually:

  1. On the device that has the data, tap Download backup below.
  2. Send that file to your other device (email, text, AirDrop, cloud drive — whatever's easiest).
  3. Open this tracker on the other device, tap Restore from backup, and pick the file.

Restoring replaces whatever is already saved on that device, so download a backup from it first if it has anything you want to keep.
